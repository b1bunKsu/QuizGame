ABOUT THE GAME

知識とスピードで、限界に挑戦。

様々なジャンルと出題形式のクイズに挑戦するゲームです。正確さと解答スピードを武器に、ハイスコアを目指しましょう。

GAME MODES

ゲームモード

01 / STANDARD

スタンダード

全25問、1問20秒。ハイスコアを競おう！

02 / HIGH SPEED

ハイスピード

全15問、1問5秒。

素早い判断力が試されるスピード勝負！

03 / CHALLENGE

100問チャレンジ

ライフ5からスタート。100問正解を目指そう。

7問連続正解するとライフが回復するぞ！
